# Хранилище и вход

Для работы сервера нужны PostgreSQL в `DATABASE_URL` и случайный секрет Auth.js в `AUTH_SECRET`. До первого запуска примените `schema.sql` к выбранной базе стандартным клиентом PostgreSQL. Схема использует `CREATE ... IF NOT EXISTS`; для следующих изменений необходимы версионированные миграции.

Пароли хешируются bcrypt, вход ограничен десятью попытками на email за 15 минут. Ограничение не заменяет защиту от распределённых запросов: перед публичным запуском необходимы защита регистрации и ограничение запросов по сети на инфраструктурном уровне. Восстановление пароля пока не реализовано. Не храните секреты в репозитории.

При создании попытки в базе сохраняется снимок вопросов и их версий. Маршруты проверяют владельца на сервере; ссылка с токеном доступна лишь после завершения и отзывается владельцем. На клиент возвращается снимок без критериев интерпретации.
