# Передача результатов

Два согласованных способа передать проход для независимого анализа. Оба строятся одной функцией
`buildExport(attempt, assessment)` из `lib/export/build.ts`, поэтому файл и страница по ссылке
показывают одно и то же.

## Файл JSON

Кнопка «Скачать» на экране завершения и на странице `/results/[attemptId]`. Имя файла:
`<assessmentId>-v<version>-<attemptId8>-<YYYY-MM-DD>.json`.

Формат `visual-assessment-export`, версия `1.0`:

| Поле | Что внутри |
| --- | --- |
| `format`, `formatVersion`, `exportedAt`, `note` | Тип и версия формата, время выгрузки, пояснение для аналитика |
| `assessment` | `id`, `version`, `title`, `description` банка вопросов |
| `attempt` | `id`, `status`, `assessmentVersion`, `startedAt`, `completedAt` |
| `summary` | Счётчики: всего, с ответом, «не уверен», пропущено, без выбора, без ответа, с отметками, с комментарием |
| `blocks[].questions[]` | `id`, `version`, `answeredVersion`, `kind`, `skills`, `prompt`, `context`, `asset`, `options`, `maxMarks`, `source`, `response`, `marks`, `comment`, `answeredAt` |
| `orphanAnswers` | Ответы на вопросы, которых нет в текущей версии банка |

`response.status`: `answered` (с `optionId` и `optionLabel`), `unsure`, `skipped`, `partial`
(есть отметки или комментарий, но вариант не выбран), `unanswered`.

Отметки (`marks`) нормированы к ширине и высоте изображения: `{ x: 0..1, y: 0..1 }`. Адреса
изображений в файле абсолютные, поэтому файл можно открыть без приложения.

В файл **не** попадают: данные аккаунта (почта, хеш пароля), токен ссылки и критерии
интерпретации из банка (`interpretation`). Поэтому анализ получается независимым.

## Ссылка на результаты

По умолчанию результаты видны только владельцу после входа (`/results/[attemptId]`). Владелец
явно создаёт ссылку `/results/share/<token>`, а отключает её кнопкой «Отключить». После этого
ссылка отвечает «недействительна или отключена». Страница по ссылке закрыта от индексации
(`robots: noindex`) и не передаёт referrer.

Открыть защищённую страницу ИИ-среда может не всегда. Надёжный путь — загрузить JSON-файл в чат.

## Изменение формата

Новые поля можно добавлять без смены версии формата. Если поле удаляется или меняется его
смысл, нужно поднять `EXPORT_FORMAT_VERSION` в `lib/export/build.ts` и описать изменение здесь.
