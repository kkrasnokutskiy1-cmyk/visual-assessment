# Дизайн-контракт

Источник истины для интерфейса платформы. Базовая система — [Fluid Functionalism](https://www.fluidfunctionalism.com/docs) (shadcn/ui, Radix). Компоненты лежат в `components/ui/*`, их токены — в `app/globals.css`.

## Принципы
- Визуальный пример — главный объект экрана. Интерфейс нейтральный, монохромный, без декоративных градиентов, иллюстраций и эмодзи.
- Один акцент: `--fluid-accent` (фокус, выделение). Для отметок на изображениях — `--mark`.
- Десктоп, ширина контента `--content-max` (1200px), текстовые колонки `--reading-max` (640px).
- Светлая и тёмная темы (`next-themes`, класс `.dark`, ключ `va-theme`), переключатель в шапке.

## Токены
| Группа | Токены |
| --- | --- |
| Цвет | `background`, `foreground`, `muted-foreground`, `border`, `surface-1…8`, `destructive`, `success`, `warning`, `fluid-accent` |
| Примеры | `--specimen-bg` (#fff в обеих темах), `--specimen-border`, `--mark`, `--mark-foreground` |
| Типографика | `text-display` 28/34, `text-title` 16/22, `text-subtitle` 14/20, `text-body` 13/20, `text-caption` 12/16, `text-micro` 11/14 (Geist, кириллица) |
| Отступы | шкала Tailwind (кратно 4px); секции — `gap-8`/`py-12`, карточки — `p-4`/`p-6` |
| Радиусы | `--radius` 10px и производные `rounded-md/lg/xl`; контролы — через `ShapeProvider` |
| Тени | `shadow-surface-1…8` (только из системы) |
| Движение | `--duration-fast` 80ms, `--duration-base` 150ms; ничего длиннее 150ms; `prefers-reduced-motion` гасит анимации глобально |

## Правила примеров
- Пример всегда рендерится на `bg-specimen` с рамкой `border-specimen-border`: смена темы не меняет сам пример.
- Сравниваемые варианты показываются в одинаковом размере и масштабе, бок о бок.
- Отметки хранятся в долях (0..1) от собственных размеров изображения.

## Состояния
Каждый экран с данными различает: загрузку (скелетон), пустые данные, ошибку с повтором, сохранение (`saving` / `saved` / `error`), восстановление прогресса.
